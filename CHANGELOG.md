# Changelog

All notable changes to the AevumDB Node.js Driver are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-11

### Added
- Initial release of the AevumDB Node.js Driver.
- Full API coverage for AevumDB CRUD operations (`insert`, `find`, `update`, `delete`, `count`).
- Connection and pooling management for efficient server communication.
- Authentication support via API keys.
- Admin operations for schema management (`setSchema`) and user creation (`createUser`).
- TypeScript-first design with comprehensive type definitions.
- Modern Promise-based API for `async/await` usage.
- Structured error handling with custom error classes.
- Examples demonstrating basic usage, connection pooling, admin operations, and error handling.

### Documentation
- Complete API Reference (`docs/API.md`).
- Guide to Connection & Pooling (`docs/CONNECTION.md`).
- Comprehensive Error Handling guide (`docs/ERRORS.md`).
- Best Practices for production use (`docs/BEST_PRACTICES.md`).
- `README.md` with quick start and overview.
- `SECURITY.md` detailing vulnerability reporting.
- `CONTRIBUTING.md` for contribution guidelines.
- `CONTRIBUTORS.md` and `AUTHORS.md` for project maintainers and contributors.
- `SUPPORT.md` for general support information.
