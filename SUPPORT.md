## Getting Help

### Installation & Setup Issues

If you encounter difficulties installing or setting up the AevumDB Node.js driver:

1.  Review the [README.md](README.md) quick start section.
2.  Verify your Node.js version (16.0.0 or higher is recommended).
3.  Ensure you have `pnpm` or `npm` installed correctly.
4.  Consult the [Connection & Pooling Guide](docs/CONNECTION.md) for detailed setup information.

### Usage Questions

For questions about how to use specific features of the driver:

1.  Refer to the [API Documentation](docs/API.md) for method details.
2.  Browse the [Examples](examples/) directory for practical code implementations.
3.  Read the [Best Practices](docs/BEST_PRACTICES.md) guide for recommended usage patterns.
4.  Search existing GitHub issues for similar questions or solutions.

### Reporting Issues

If you believe you've found a bug or encountered an unexpected issue:

1.  **Search**: Before opening a new issue, please search the [GitHub Issues](https://github.com/aevumdb/aevum-node/issues) to see if it has already been reported.
2.  **Reproduce**: Create a minimal, reproducible example that clearly demonstrates the bug. This helps us to quickly understand and fix the problem.
3.  **Report**: [Create a new issue on GitHub](https://github.com/aevumdb/aevum-node/issues) and include the following information:
    *   A clear and concise description of the problem.
    *   Your environment details (e.g., Node.js version, operating system, driver version).
    *   Detailed steps to reproduce the issue.
    *   The expected behavior versus the actual behavior.
    *   Any relevant error messages or logs.

### Security Issues

**Do not create public issues for security vulnerabilities.**

Please refer to our [Security Policy](SECURITY.md) for responsible disclosure procedures and how to privately report security concerns.
